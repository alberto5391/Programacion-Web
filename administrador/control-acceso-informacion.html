Operaciones controladas

  • Consultar: permite visualizar información de acuerdo con los permisos.
  • Registrar: permite agregar nuevos registros cuando el usuario tiene autorización.
  • Modificar: permite actualizar información cuando el rol lo permite.
  • Eliminar lógicamente: permite desactivar registros sin eliminarlos físicamente de la base de datos.

Seguridad de acceso

Las operaciones no autorizadas deberán ser bloqueadas por el sistema y se deberá mostrar un mensaje indicando que el usuario no cuenta con los permisos necesarios.

Ejemplo: "Acceso denegado. No tienes permisos para realizar esta operación."
